Pixel Runner
a simple and fun 2D endless runner game built using python and pugame

The player controls a charcater that must jump over incoming obstaclea and survive as along as possible the score increases the time you survive

Features:-

simple keyboard contols
player running animation
Flying obstacles
Gound obstacles
jump mechanics with gravity
collision detction
background music
jumo sound effect
time-based scoring system
game restart afetr collison
pixel-art style graphics


Technologies Used

python
pygame


How to run

open the project

cd pygame-runner

install pygame
pip install pygame


Run the game
python 1.py
